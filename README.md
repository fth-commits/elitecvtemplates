## 🚀 Deployment

This website is built with React + Vite + Tailwind CSS and is ready for GitHub Pages deployment.

### Deploy to GitHub Pages

1. Create a new repository on GitHub
2. Upload all files from this folder to your repository
3. Go to Settings > Pages
4. Select "Deploy from a branch"
5. Choose "main" branch and "/ (root)" folder
6. Click Save

Your site will be live at `https://yourusername.github.io/your-repo-name`

## 📝 Custom Domain (Optional)

To use a custom domain:

1. Add your domain in the repository Settings > Pages > Custom domain
2. Create a `CNAME` file in the root with your domain name
3. Update your DNS settings to point to GitHub Pages
